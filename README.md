# 2026 포트폴리오 · 우리FIS 지원본

`woorifis-portfolio` 브랜치에서 [우리FIS IT자원관리/운영 공고](https://careers.woorifis.com/job_posting/rxSudutW)에 맞춰 구성한 버전입니다. 선택한 초기 이력서형 디자인을 재사용했습니다.

## 지원본 구성

1. IT 운영 자산·유지보수·예산 관리
2. SSL/TLS 인증서 배포·현황관리 자동화
3. 서버 보안 기준선·ISMS 조치와 운영 증적
4. IT 재해대응 절차 점검·도상훈련 참여

ELK 중앙 로그, 입·퇴사자 증적 자동화, 온라인 멤버십 시스템(ABC-CAMP)은 보완 경험으로 유지합니다. 각 대표 사례는 담당 범위, 판단 기준, 결과·산출물, 근거 자료를 구분합니다.

## 표현·공개 범위

- 예산은 부서 월별 보고·관리 파일 유지·전용 및 이월 신청 경험이며 집행·승인 권한으로 표현하지 않습니다.
- 재해대응은 도상훈련 참여 경험입니다. 실제 DR센터 전환, AWS DR 구축, 목표 복구시간 달성을 주장하지 않습니다.
- SSL 25대는 2026년 9월 운영 적용 수치이며 다른 시점의 탐지·계획 대상 수와 혼용하지 않습니다.
- 위험조치 진행률은 2026년 7월 기록입니다. 공용 산출물 전체를 개인 작성물로 표현하지 않습니다.
- 금융권·전용 CMDB/ITSM 경험은 확인된 경력으로 제시하지 않습니다.
- 원본 예산·계약·훈련 자료, 내부 주소·계정·연락처·금액은 저장소에 포함하지 않습니다.

이 브랜치를 선택한 저장소 폴더에서 `python -m http.server 4176 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:4176/`을 엽니다. 별도 빌드나 패키지 설치가 필요하지 않습니다.

## 제출용 PDF

- [우리FIS 제출용 포트폴리오 PDF](output/pdf/김소령_우리FIS_IT자원관리운영_포트폴리오.pdf): A4 가로 12쪽, 검색·복사 가능한 한글 텍스트와 페이지별 목차 포함.
- 표지, 직무 연결, 핵심 사례 4개, 운영 도구·ABC-CAMP 보완 경험, 기여 방향, 근거 목록으로 구성했습니다.
- 첨부된 우리은행 디자인 참고 자료의 흰 바탕, 검정·회색 본문, 각진 구획과 절제된 블루를 적용했습니다. 공식 로고나 그라데이션은 사용하지 않았습니다.
- 도식과 표는 업무자료 기반 비식별 재구성이며 원본 화면 캡처로 표현하지 않습니다. 사용 글꼴은 가독성을 위한 맑은 고딕으로, 공식 브랜드 서체라는 의미가 아닙니다.

수정 가능한 원본은 `tools/build_woorifis_portfolio.py`입니다. 다른 PC에서도 이 브랜치를 내려받으면 PDF와 원본을 함께 사용할 수 있습니다.

다시 만들 때는 Python과 `reportlab`이 필요합니다.

```sh
python -m pip install reportlab
python tools/build_woorifis_portfolio.py
```

Windows는 설치된 맑은 고딕을 사용합니다. 다른 환경은 `--font`와 `--bold-font`로 한글 TrueType 글꼴을 지정합니다. 글꼴 원본은 저장소에 배포하지 않습니다. 생성 시 페이지 수·문구·텍스트 영역 크기를 검사하며, 최종 제출 전 PDF 화면도 확인합니다.
